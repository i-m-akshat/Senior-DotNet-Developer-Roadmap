## RESEARCH FINDINGS

### Infosys .NET Interview Pattern (from Glassdoor, Reddit, Naukri)
1. **Process**: Online assessment (if lateral) → 1-2 Technical Rounds → HR Round
2. **Resume Deep Dive**: Interviewers read resume line-by-line; know everything you've written
3. **Technical Focus Areas (in priority order)**:
   - C# & OOP (4 pillars, interface vs abstract class, SOLID)
   - ASP.NET Core (DI lifetimes, middleware, JWT auth)
   - EF Core (N+1, tracking, migrations)
   - SQL (joins, indexes, window functions, optimization)
   - Design Patterns (Singleton, Factory, Repository)
   - Basic DSA (strings, arrays, collections logic tests)
4. **Coding Tests**: Basic logic problems — reversal, duplicates, string manipulation
5. **Expected Depth for 3 YOE**: "Why" not just "What" — must explain reasoning
6. **Common Traps Interviewers Use**:
   - "What happens if you inject Scoped into Singleton?" (Captive Dependency)
   - "Does async/await create a new thread?" (No — state machine)
   - "What is the difference between IEnumerable and IQueryable?"
   - "How do you handle JWT invalidation?"
   - "What is the N+1 problem and how do you fix it?"
   - "Is Singleton an anti-pattern?"

### Key Interview Advice from Candidates
- Be absolute master of what's on your resume
- Clarity over speed — admit you don't know rather than bluffing
- Prepare project architecture walkthrough in advance
- Agile/Scrum questions likely (stand-ups, sprint planning)
